# User stories

- As a user, I can select interests so my feed begins relevant to me.
- As a user, I can open an article and receive a concise, sourced summary.
- As a user, I can compare labelled perspectives without mistaking them for facts.
- As a user, I can ask questions about an article and see grounded source references.
- As a user, I can choose Gemini or a locally running Ollama model in settings.
- As a user, I can bookmark articles and return to them later.
